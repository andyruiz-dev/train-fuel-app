Starting level per movement pattern

Sets where a fresh, never-trained muscle group begins. Once you've logged a workout for a group, this no longer touches it — auto-progression from your rep ranges takes over from there. Not sure which to pick? Beginner = you've never done structured exercise for this movement before; Intermediate = you've trained it on and off, casually, for a while; Advanced = you've followed a structured program for it before. When in doubt, pick Beginner — it's easy to move up once a few workouts feel too easy, and much safer than starting too hard. Push and pull are split into "horizontal" and "vertical" because they're trained as separate progressions: horizontal push/pull is push-ups and rows, vertical push/pull is overhead presses and pull-ups — set each independently.

Ring strap setting (push)

Only matters if you're training ring push exercises (ring push-ups, ring dips) — skip this otherwise. It tracks how horizontal your ring push-ups are set to (lower number = more horizontal = harder), separate from the beginner/intermediate/advanced level above. Auto-adjusts by 0.5 after any workout that includes a ring push exercise: hit max reps and it recommends one notch lower next time; miss and it backs off one notch higher. Push-only — pull's path to a pull-up is a different, vertical-pattern progression (dead hang → negatives → band-assisted → pull-up), not row horizontality, so it's handled by the level system above instead.

Daily macro targets

New to tracking macros? A simple starting point: protein around 0.7-1g per lb of your bodyweight, calories around what keeps your weight roughly steady right now (lower it a bit if the goal is fat loss), and carbs/fat split to fill out the rest. You don't need to get this exact — log for a week or two and the Coach's weekly suggestions on the Coach tab will nudge these for you from there.
